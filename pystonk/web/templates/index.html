Current Scope

Quote, history, and option setup

The web app currently covers the same three core tasks as the Slack version: check the underlying, inspect threshold-based move history, and find weekly option candidates.

Guardrails

Candidate quality is now visible

Option recommendations can now carry market-quality warnings so wide spreads, zero bids, and thin open interest are harder to ignore.

JSON API

Keep the backend reusable

Normalized endpoints remain available at /api/quote, /api/history, and /api/options so Slack and future automations can reuse the same services.

Runtime

FastAPI entrypoint: pystonk.web_app:app

Workspace DB

Default path: pystonk.sqlite3 or override with PYSTONK_WEB_DB_PATH

Credentials

Set PYSTONK_SCHWAB_KEY and PYSTONK_SCHWAB_SECRET before live use.
